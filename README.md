#  Python Assignment 2 – Data Structures & Conditional Statements

## Overview
This assignment is part of my Python learning journey in AI-Driven Data Analytics. It focuses on understanding and applying Python data structures such as lists, dictionaries, and sets, along with conditional statements.

## Learning Objectives
- Understand list creation, access, and modification.
- Perform dictionary operations using keys, values, and items.
- Explore set properties and set operations.
- Apply conditional statements using `if`, `elif`, and `else`.
- Use operators and logical conditions to solve basic problems.

## Tasks Completed

### 1. List Operations
- Created and modified lists using append, insert, remove, pop, and extend.
- Sorted list elements in descending order.
- Used `max()`, `min()`, and `sum()` to perform basic operations.
- Practiced indexing, slicing, and reversing list elements.

### 2. Dictionary Operations
- Created a dictionary to store student names and marks.
- Accessed, added, and updated student records.
- Used `keys()`, `values()`, and `items()` to retrieve dictionary data.

### 3. Set Operations
- Created sets and explored how duplicate elements are handled.
- Examined set mutability and element access.
- Performed union and intersection operations on two sets.

### 4. Conditional Statements
- Developed a performance categorization program based on user input.
- Used `if`, `elif`, and `else` to classify scores into Above Average, Average, and Below Average categories.
- Displayed suitable feedback for each performance category.
